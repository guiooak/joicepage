# Original images

The images as exported from the `.fig`, before conversion to WebP. The pages
ship the `.webp` versions in `raw/web/assets/img/` and
`raw/mobile/assets/img/`; these are kept as the source to re-encode from, so
a change of format or quality never has to start from an already-compressed
file.

Both pages use the same files, except `icon-01.png`, whose mobile export
differs — that one is in `mobile/`.

Not deployed: the build copies only `raw/web` and `raw/mobile`.
